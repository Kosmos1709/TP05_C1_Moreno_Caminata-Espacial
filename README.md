# Emy

Emy es un juego arcade de supervivencia desarrollado en Unity.

La protagonista, Emy, se encuentra flotando a la deriva en el espacio mientras diversos alienígenas intentan impedir su avance. El objetivo es sobrevivir durante el mayor tiempo posible esquivando peligros y aprovechando los buffs que aparecen durante la partida.

## Gameplay

* Controla a Emy mientras asciende constantemente.
* Evita ser atrapada por los alienígenas.
* Recoge pociones para obtener ventajas temporales.
* Intenta superar tu récord personal.

## Controles

|Acción|Tecla|
|-|-|
|Saltar / Ascender|Espacio|

## Buffs

### Extra Life

Otorga una vida adicional.

### Invincible

Hace a Emy invulnerable durante unos segundos.

### Slow Time

Reduce temporalmente la velocidad del juego para facilitar la evasión de obstáculos.
